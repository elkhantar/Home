# Personal fork workflow

Read README.md, SECURITY.md and `docs/review/INDEPENDENT-FORK-REVIEW.md`. Build locally with build-personal.ps1.
Do not run upstream debloat/theme/install commands on the TV: this fork has a separate package
ID and private configuration storage. Build and review the candidate before installing; coordinate TV controls with the owner. Keep the TV's existing screensaver and DNS unchanged.
